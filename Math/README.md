# Math Algorithms

This directory contains mathematical algorithms and number theory implementations.

## 📚 Mathematical Algorithms

Mathematical algorithms are fundamental building blocks for solving many computational problems efficiently.

## 📁 Files

- `Gcd.py` - Greatest Common Divisor
- `Armstrong.py` - Armstrong numbers
- `palindrome.py` - Palindrome checking
- `primes.py` - Prime number algorithms
- `countdigits.py` - Count digits in numbers
- `Divisors.py` - Divisor calculations
- `reverse.py` - Number reversal

## 🎯 Topics Covered

### Number Theory
- **GCD (Greatest Common Divisor)** - Euclid's algorithm
- **LCM (Least Common Multiple)** - Using GCD
- **Prime Numbers** - Sieve of Eratosthenes
- **Armstrong Numbers** - Sum of powers of digits
- **Palindromes** - Number palindrome checking

### Number Operations
- **Digit Counting** - Count digits in number
- **Number Reversal** - Reverse number digits
- **Divisors** - Find all divisors
- **Factors** - Prime factorization

## ⏱️ Common Complexities

| Algorithm | Time |
|-----------|------|
| GCD (Euclid) | O(log min(a,b)) |
| Prime Check | O(√n) |
| Sieve | O(n log log n) |
| Factor | O(√n) |

## 💡 Tips

- Understand Euclid's algorithm for GCD
- Use Sieve for multiple primes
- Recognize patterns in palindromes
- Practice modular arithmetic

# Searching Algorithms

This directory contains implementations of search algorithms.

## 📚 Searching Algorithms

Searching is the process of finding a specific element in a collection. Different algorithms have different complexities and work best with different data arrangements.

## 📁 Files

- Linear search implementations
- Search utilities

## 📊 Common Searching Algorithms

| Algorithm | Time | Best For | Notes |
|-----------|------|----------|-------|
| Linear Search | O(n) | Unsorted data | Simple, works on any array |
| Binary Search | O(log n) | Sorted data | Fast, requires sorted input |
| Hash Table Search | O(1) avg | Key-value pairs | Very fast average case |

## 🎯 When to Use

### Linear Search
- Array is small
- Array is unsorted
- Need to find all occurrences
- Simplicity is priority

### Binary Search
- Array is large
- Array is sorted
- Need single element
- Performance is critical

## 📖 Prerequisites

- Arrays
- Basic loops
- Time complexity analysis

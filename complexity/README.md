# Complexity Analysis

This directory contains resources for understanding and analyzing algorithm complexity.

## 📚 Complexity Analysis

Understanding time and space complexity is crucial for algorithm design and optimization.

## 📁 Directories

- `Time complexity/` - Time complexity analysis
- `spacecomplexity/` - Space complexity analysis

## 🎯 Big O Notations

- O(1) - Constant
- O(log n) - Logarithmic
- O(n) - Linear
- O(n log n) - Linearithmic
- O(n²) - Quadratic
- O(2^n) - Exponential
- O(n!) - Factorial

---

**Always analyze complexity before implementation!** 📊

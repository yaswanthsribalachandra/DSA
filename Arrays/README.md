# Arrays

This directory contains implementations and problems related to array data structures and operations.

## 📚 Topics Covered

- **Array Basics**: Indexing, initialization, traversal
- **Array Operations**: Finding max/min, sum, counting elements
- **Array Search**: Linear search, searching for specific elements
- **Array Sorting**: Checking if array is sorted
- **Array Manipulation**: Rotation, rearrangement, transformation

## 📁 Files

- `basics.py` - Basic array operations
- `largest.py` - Find largest element in array - **O(n)**
- `secondlargest.py` - Find second largest element - **O(n)**
- `minimum.py` - Find minimum element - **O(n)**
- `sum.py` - Calculate sum of array elements - **O(n)**
- `countodd.py` - Count odd numbers in array - **O(n)**
- `indexing.py` - Array indexing demonstrations
- `issorted.py` - Check if array is sorted - **O(n)**

## 🎯 Learning Objectives

After studying this section, you should be able to:
- ✅ Understand array indexing and bounds

- ✅ Write O(n) linear search algorithms
- ✅ Solve common array problems

## 🔗 Time Complexities

| Operation | Best | Average | Worst |
|-----------|------|---------|-------|
| Access | O(1) | O(1) | O(1) |
| Search | O(1) | O(n) | O(n) |
| Insert | O(1) | O(n) | O(n) |
| Delete | O(1) | O(n) | O(n) |

## 💡 Usage Examples

```python
from Arrays.largest import largest

# Find largest element
result = largest([3, 7, 2, 9, 1])  # Returns: 9
```

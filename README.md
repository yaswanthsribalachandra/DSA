# Data Structures and Algorithms (DSA) Learning Repository

A comprehensive Python implementation of fundamental data structures and algorithms, organized by topic for easy learning and reference.

## 📚 Repository Structure

```
DSA/
├── Arrays/                 # Array operations and manipulations
├── Basics/                 # Fundamental programming concepts
├── Binary Trees/           # Tree data structure and traversals
├── Binarysearch/           # Binary search implementations
├── Bit_Manipulation/       # Bit manipulation techniques
├── Dynamic Programming/    # DP approaches and problems
├── LinkedList/             # Linked list implementations
├── Math/                   # Mathematical algorithms
├── Queues/                 # Queue data structure
├── Recursion/              # Recursive approaches and patterns
├── Stacks/                 # Stack data structure
├── Strings/                # String algorithms
├── complexity/             # Time and space complexity analysis
├── searching/              # Search algorithms
└── sorting/                # Sorting algorithms
```

## 🎯 Topics Covered

### Core Data Structures
- **Arrays**: Array operations, searching, manipulation
- **LinkedList**: Singly/Doubly linked lists, queue/stack operations
- **Stacks**: LIFO operations, applications
- **Queues**: FIFO operations, priority queues
- **Binary Trees**: Tree traversals (DFS, BFS), tree operations

### Algorithms
- **Sorting**: Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Hash-based sorting
- **Searching**: Binary Search, Linear Search
- **Recursion**: Functional and backtracking approaches
- **Dynamic Programming**: Memoization and optimization
- **String Algorithms**: String manipulation and analysis
- **Math Algorithms**: GCD, Prime numbers, Armstrong numbers, Palindromes, etc.
- **Bit Manipulation**: Bit operations and techniques

### Analysis
- **Time Complexity**: Algorithm runtime analysis
- **Space Complexity**: Algorithm memory usage analysis

## 🚀 Quick Start

### Prerequisites
- Python 3.7+

### Installation
```bash
git clone https://github.com/yaswanthsribalachandra/DSA.git
cd DSA
```

### Running Examples
Each topic folder contains Python files with example implementations:
```bash
python Arrays/largest.py
python sorting/bubblesort.py
python Recursion/print_name.py
```

## 📖 Learning Guide

Follow this recommended learning path:

1. **Start with Basics**
   - Loops and control flow
   - Pattern printing

2. **Master Core Data Structures**
   - Arrays → LinkedList → Stacks → Queues
   - Binary Trees

3. **Learn Algorithms**
   - Sorting algorithms
   - Searching techniques
   - Recursion and backtracking

4. **Advanced Topics**
   - Dynamic Programming
   - Bit Manipulation
   - Complex problem solving

See [LEARNING_GUIDE.md](./LEARNING_GUIDE.md) for detailed learning paths with prerequisites.

# Queues

This directory contains queue data structure implementations.

## 📚 About Queues

Queue is a **FIFO (First In First Out)** data structure where elements are added at the rear and removed from the front.

## 📊 Core Operations

```python
enqueue(element)  # Add to rear - O(1)
dequeue()         # Remove from front - O(1)
peek()            # View front element - O(1)
isEmpty()         # Check if empty - O(1)
```

## ⏱️ Time Complexities

| Operation | Time |
|-----------|------|
| Enqueue | O(1) |
| Dequeue | O(1) |
| Peek | O(1) |
| Space | O(n) |

## 💡 Applications

- **BFS** - Breadth-first search
- **Level-order traversal** - Tree traversal
- **Job scheduling** - Task management
- **Print queue** - Document printing
- **Traffic management** - Flow control
